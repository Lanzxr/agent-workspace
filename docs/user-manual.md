# Company Agent 使用手册

适用对象：企业管理员（L3）、企业员工（L2）、QQ / 企业微信（WeCom）群管理员与中控台运维人员。  
所有能力均受后端控制面校验：**大语言模型不拥有绕过身份校验、群聊隔离、沙箱断网或读取宿主机密钥的权限**。

---

## 一、权限分级与隔离模型

| 层级 | 适用场景 | 知识库范围 | 工具与 MCP 能力 | 写入/发布权限 |
|---|---|---|---|---|
| **L1 客户/默认群** | 未定级 QQ 群 / 企微群、客户沟通群 | 仅本群资料；显式向下兼容（`compat`）开启时才可额外访问 `common` | 仅 `common` 公共 `shared-tools`、允许 `common` 的外部 MCP 与已批准 `visibility=common` 的动态工具 | 禁止 `/internal`；禁止 `/forge-*` |
| **L2 内部群 / 员工私聊** | 管理员设为内部群的群聊、已绑定员工的 QQ / 企业微信私聊 | 本群/本会话资料 + 公司内部共享知识库 | `common` + `internal` 工具库、授权 `internal` 的 MCP 与 `visibility=internal/common` 的动态工具 | 允许在私聊或内部群用 `/internal` 补充内部知识；禁止 `/forge-*` |
| **L3 管理员** | 绑定为 `admin` 的成员；Tool Forge 配置/审批仅限 **管理员本人 QQ / 企业微信私聊** | 全部范围资料与审计日志 | 全部工作区工具 + `forge_admin` 工具工坊 MCP（试调外网、起草、测试、提交提案） | 管理群分级、发放绑定码、外网白名单/凭据与工具发布终审 |

> [!IMPORTANT]
> **房间天花板原则**：即便管理员或员工本人拥有 L2/L3 身份，只要发言发生在 **L1 客户群**，该会话依然被限制在 L1 安全沙箱内，不会泄露内部知识、内部脚本或内部 MCP 工具。

## 二、初次使用：成员创建与聊天账号身份绑定（QQ / 企业微信通用）

> [!NOTE]
> 如启用企业微信长连接机器人，管理员**无需配置公网回调域名**，启动 `company-agent-wecom.service` 后，新成员首次打开与机器人的企微私聊窗口会自动收到欢迎语，并可通过同一套 `/bind` 与 `/whoami` 指令绑定身份；QQ 与企业微信可分别独立启用或双渠道并行。

1. **打开本地管理控制台**：在宿主机访问 `http://127.0.0.1:28765`（如已修改 `COMPANY_AGENT_ADMIN_PORT` 或 `COMPANY_AGENT_PORT_BASE` 则用对应端口），使用 `runtime.env` 中配置的 `COMPANY_AGENT_ADMIN_TOKEN` 登录。
2. **创建内部成员并生成绑定码**：
   - 进入「**员工·管理员与绑定**」页签，创建成员并选择角色（`admin` 管理员 或 `employee` 员工）。
   - 在成员列表中点击「生成绑定码」，复制类似 `/bind ABCD-1234` 的一次性指令发给对应同事。
3. **QQ / 企业微信端自助完成绑定**：
   - 成员在**与机器人的 QQ 或企业微信私聊**（或群内 `@机器人 /bind <绑定码>`）发送 `/bind <绑定码>`。
   - 绑定后可随时发送 `/whoami` 核对当前身份角色和所在会话的安全层级；也可在控制台「**员工·管理员与绑定**」的未绑定发送者列表选择所属平台（`QQ` / `企业微信`）一键绑定。
4. **管理员标记企业内部群**：
   - 新加入的 QQ 群与企业微信群默认一律为 **L1 客户隔离群**，并按群分配互不互通的隔离工作区。
   - 管理员进入需要放开内部共享能力的群聊，发送 `/mark-internal`（企微群内若开启提及要求，发送 `@机器人 /mark-internal`）升级为 L2 内部群；如需降回客户隔离群，发送 `/mark-client`。

## 三、聊天端全量指令速查表（QQ / 企业微信通用）

### 3.1 通用与群管指令

| 指令 | 使用位置 | 所需角色 | 作用说明 |
|---|---|---|---|
| `/whoami` | 任意私聊 / 群聊 | 所有人 | 查看当前账号绑定角色及所在聊天层（L1 / L2 / 私聊） |
| `/bind <绑定码>` | 任意私聊 / 群聊 | 持码人 | 将当前 QQ 或企业微信账号绑定到控制台创建的内部成员（绑定码单次有效） |
| `/mark-internal` | QQ 群 / 企微群内 | L3 管理员 | 将当前群设为企业内部群（L2），解锁内部知识库与内部工具 |
| `/mark-client` | QQ 群 / 企微群内 | L3 管理员 | 将当前群设为客户隔离群（L1），严格隔离内部资源 |
| `/compat on \| off \| inherit` | QQ 群 / 企微群内 | L3 管理员 | 控制单群是否向下兼容读取 `common` 公共层内容 |
| `/internal <正文>` 或带附件 | 管理员/员工私聊、L2 内部群 | L2 员工 / L3 管理员 | 将文本经验或附件直接沉淀到企业内部共享知识库（L1 客户群内禁用） |
| `/save-internal <正文>` | 同上 | 同上 | `/internal` 的别名指令 |

### 3.2 Tool Forge 管理员工具工坊指令（仅限 L3 管理员私聊）

> [!CAUTION]
> 为防止密钥或高危操作在多人环境误发与暴露，以下全部 `/forge-*` 指令**在任何 QQ 群与企业微信群内均会被直接拦截拒绝**，仅允许在**已绑定为 L3 管理员的本人 QQ 或企业微信私聊窗口**使用。

| 指令 | 作用说明 |
|---|---|
| `/forge` 或 `/forge-help` | 查看 Tool Forge 全部管理员指令与用法说明 |
| `/forge-domain list` | 查看当前已放行的外网域名白名单 |
| `/forge-domain add <域名> [--subdomains]` | 将外部接口域名加入白名单（加 `--subdomains` 同时放行子域名；默认严禁任何未授权外网请求） |
| `/forge-domain del <域名>` | 将指定域名移出外网白名单 |
| `/forge-secret list` | 查看已配置的第三方凭据别名及脱敏长度预览（**不显示明文**） |
| `/forge-secret set <别名> <密钥值>` | 将第三方 API Token/Secret 加密写入 `0600` 宿主机凭据保险库；**入库及送交上游前系统已自动抹除聊天记录与上下文中的明文** |
| `/forge-secret del <别名>` | 删除不再使用的托管凭据 |
| `/forge-proposals` | 查看当前所有待审批上线提案（包含 `proposal_id`、作用域、依赖域名与凭据别名） |
| `/forge-approve <proposal_id>` | **管理员人工终审批准**：将指定版本立即热上线至 `admin` / `internal` / `common`（或写入 `shared-tools`），无需重启服务 |
| `/forge-reject <proposal_id> [原因]` | 驳回待审批提案并记录原因 |
| `/forge-tools` | 查看所有已登记动态工具的活跃版本、作用域、启用状态、成功调用次数及平均耗时 |
| `/forge-enable <tool_id>` | 启用已部署工具，对应层级的用户即可继续调用 |
| `/forge-disable <tool_id>` | 立即停用问题工具，所有层级即刻不可再调用 |
| `/forge-rollback <tool_id> [vN]` | 一键回滚到紧邻上一已审批版本或指定版本号 `vN` 并立即重新激活 |

## 四、日常协作流程

### 4.1 群聊双模式：直接响应与静默感知

- **直接提问（Direct）**：@机器人 或直呼预设别名（可在控制台修改 `bot_aliases`），机器人直接评估并按权限执行任务（查资料、调用已授权 MCP/自定义工具、生成 Excel/Word/图表文件回传）。
- **静默旁听与冷静期触发（Ambient Cooldown）**：在启用群聊感知的群里，大家围绕某个问题讨论却未主动 @机器人 时，话题冷却默认 **300 秒**后由 DSSuperAgent 判断：
  - 确实能帮上忙且有对应工具/知识时，静默完成分析并主动输出结构化结果；
  - 若发现缺乏必要接口或脚本，**不打扰群聊**，自动沉淀到控制台「**需求洞察与提升**」页签供管理员后续补齐。

### 4.2 管理员一站式「对话造工具」并发布给员工群

1. **配置依赖的域名与凭据**（在管理员 QQ / 企业微信私聊发送，不经大模型）：
   - `/forge-domain add api.example.com`
   - `/forge-secret set BIZ_API_KEY sk-example-placeholder`
2. **用自然语言下达研发任务**（仍在管理员私聊）：
   - 例如：*“用凭据 `BIZ_API_KEY` 帮我试调 `https://api.example.com/v1/logs` 看下分页结构，然后写一个按模型统计 token 用量的复用工具，默认给 `internal` 员工群使用。”*
   - AI 会自动调用 `forge_probe_http` 探针试跑 → `forge_draft_tool` 起草工具 → `forge_test_tool` 跑通测试 → `forge_submit_release` 提交上线提案并把脱敏测试结果及 `proposal_id` 发给你。
3. **管理员本人核验批准**：
   - 在管理员私聊回复 `/forge-approve <proposal_id>`（或去控制台「共享工具与组件」点「批准上线」）。
   - 批准后工具**秒级热挂载到 `forge_internal`**，内部员工群下一次提问即可直接调用，无需重启服务。
4. **后续维护与升级**：
   - 在管理员私聊让 AI 改脚本或加参数时，系统会创建 `v2` 草稿——**`v1` 在线业务零中断**；确认 `v2` 测试通过并再次 `/forge-approve` 后无缝切换；线上如发现异常，直接 `/forge-rollback <tool_id>` 或 `/forge-disable <tool_id>` 即刻生效。

### 4.3 文件上传、富媒体消息与 15 天留存

- **多模态与附件自动解密**：
  - 企业微信端发送的语音会自动转写为文本，图文混排与引用消息会合并提取正文和引用附件；
  - 企微加密图片/文件在接入层自动完成 AES-256-CBC（32 字节 PKCS#7 填充）解密并抹除内存密钥，不会将临时解密密钥落盘。
- **文件交付**：用户可在任务中让 Agent 基于上传文件做统计、生成 `.xlsx`/`.docx`/`.pdf` 报告并直接回传 QQ 或企业微信群/私聊（企微支持最大 50 MiB 分片上传，且长耗时任务自动以“先即时确认 + 完成后主动推送 Markdown/文件”方式突破 10 分钟流式回复限制）；也可以进入控制台或通过历史追踪查看产物。
- **留存期限**：工作区中的输入原件、过程文件与产出物默认保留 **15 天**（可在控制台 `1–365` 天调整，支持手动立即清理过期文件或在线下载）。

## 五、Web 管理控制台（`http://127.0.0.1:28765`）页签说明

| 页签名称 | 核心功能 |
|---|---|
| **对话与链路** | 按会话列表查看全部 QQ / 企业微信群与私聊消息；点击任一条消息即可打开全链路追踪（原始事件 → DSSuperAgent 判断 → Work Item → DSH 执行日志 → Outbox 投递） |
| **系统状态** | 查看服务存活心跳（Admin / QQ Gateway / 企业微信长连接网关 `WeCom Gateway`）、任务状态统计、活跃 DSH 执行及最近任务明细 |
| **员工·管理员与绑定** | 新建企业成员、调整角色（`admin` / `employee` / `customer`）、生成 `/bind` 绑定码、按平台（`QQ` / `企业微信`）查看最近活跃未绑定发送者并快速绑定/解绑 |
| **群聊与知识隔离** | 调整各 QQ 群与企业微信群的层级（L1 / L2）与向下兼容模式；跨群/跨库显式分享特定文档；查看及清理工作区留存文件与在线下载 |
| **共享工具与组件** | 安装 `common` / `internal` 层 Python 依赖包（如 `openpyxl`、`pandas`）与离线脚本；热管理受控 MCP 服务；管理 Tool Forge 域名白名单、凭据保险库、**审批发布队列**及**工具启停/回滚** |
| **需求洞察与提升** | 查看静默感知模式沉淀的能力缺口记录（缺脚本、缺 Python 包、缺知识库或缺外部 API），一键跳转配置并标记已补齐 |
| **定时任务** | 新建与管理跨时区 UTC 调度的定时续接任务（支持失败重试与取消） |
| **权限与联网开关** | 独立开关 DSSuperAgent 与 DSH 各自的网络检索授权、全局向下兼容、群聊静默感知开关、冷却时长、机器人别名及文件留存天数 |
| **审计与执行日志** | 按实体类型/关键字筛选控制面审计流水，以及按 Workspace / Execution ID 查看 DSH 标准输出与错误日志 |
